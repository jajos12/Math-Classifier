# Math-Classifier
Experimentation to use classifier models in maths proof search.

## Laya experiment

The standalone GNN/Laya benchmark lives in
[`laya_experiment/`](./laya_experiment/). It can be cloned and run
independently from Google Colab or a server. See its
[README](./laya_experiment/README.md) for installation, model/dataset sources,
benchmark commands, outputs, and Laya training-data preparation.
